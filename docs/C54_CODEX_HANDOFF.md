## 이번 코드의 의미

1. **일봉 지지와 과거 주봉의 관계:** 현재 일봉 지지의 무효화선보다 이전 주봉 종가가 낮다는 사실만으로 일봉 진입을 자동 대기시키지 않는다. 현재 선택 지지 기준의 비교와 과거 이탈 사건의 증거 유무를 구분한다. 선택 기간 자체의 무효화·손익비·현재 가격 조건은 계속 적용한다.
2. **사유와 행동:** 같은 진입 평가 결과에서 위치·경고·대기 사유·확인 조건·최종 행동을 만든다. 새로운 가격 임계값이나 적정가를 만들지 않는다. 구간 안이라는 이유만으로 사업 위험이나 가치평가 대기를 지우지 않는다.
3. **후보 부재:** 기존 후보 진단을 활용한다. 참고 S/R을 자동으로 진입 구간으로 승격하지 않으며, 특정 종목용 예외를 넣지 않는다.
4. **PBR:** 이미 유효한 공급자 지표를 기존 PER/fPER 경로와 함께 B2에 전달한다. 낮은 PBR만으로 저평가·매력 판정을 강제하지 않으며, 자산·수익성·사업 맥락이 부족하면 중립적인 평가가 가능하다. 새 인증·사용권 계층은 없다.
5. **표시 날짜:** 지표 기준일이 있으면 그 날짜, 없으면 조회 시각을 정확히 구분한다. 조회 시각을 지표 산출일로 대신하지 않는다. Finnhub FY1 제품 정책과 KIS 애널리스트 추정치 활용 합의는 유지한다.

C52의 15개 원문과 원래 판단은 보존한다. C54의 합성 입력 렌더 시험 또는 원본 진단을 C52의 새로운 수락·새 문안으로 보고하지 않는다. C53에서 확인한 KRX 최신 봉 미반환을 이 작업으로 해결했다고 보고하지 않는다.

가격이 선택 지지 위에 있으면 기존 가격 조정 대기 정책을 유지한다. 문안의 주봉·저가 일시 이탈 확인 조건은 다음에 필요한 확인을 뜻하며, 그 조건 하나가 충족됐다고 다른 진입 조건까지 모두 충족됐다는 뜻은 아니다.

## 2. C52 기존 입력 확인 — 기존 읽기 도구 사용

먼저 기존 C52 사후 확인 결과에 필요한 입력 진단이 이미 있는지 확인한다. 없다면 원래 소비자 실행 디렉터리를 `model-runtime-preflight.json`의 `execution` 및 원래 terminal에서 확인한다.

원래 generation:

```text
/Users/sskim/Documents/Codex/2026-07-04/the/work/thesis-monitor-pr52-local-launchd-20261119/data/local-launchd/runs/c52-us-20261125-full/one-shot/2026-11-25/us-20261125-c52a1b2c
```

`C52_CONSUMER`는 위 generation 자체가 아니라 `b2/request.json`, `b2/<ticker>/request.json`, `b2/canonical/...`, 원래 terminal이 있는 실제 소비자 디렉터리다. 기존 `scripts/c49_inspect_saved_inputs.py`가 원래 후보 진단·선택 결과와 가치평가 날짜를 함께 읽도록 보완돼 있다.

```bash
"$C54_PY" -m scripts.c49_inspect_saved_inputs \
  --cycle "$C52_CONSUMER" \
  --output "$C54_RESULT_DIR/C52_QUALITY_INPUTS.json"
```

이 도구는 저장 파일을 읽는 진단이다. 기존 해시·B/B2 수락본을 고치지 않으며, Source 재수락·사용권 재발급·모델 호출·전체 문안 재생을 수행하지 않는다.

### 확인할 항목

- **CORZ·CRCL·MU·RXRX·SKHY·SNDK·WRD:** 원래 `entry_candidate_diagnostics`, 선택 ID, 타이밍 입력으로 적격 후보가 없었는지 또는 선택 연결이 없었는지 구분한다. 미선택 참고 지지는 그 가격을 제시한 것만으로 적격으로 취급하지 않는다.
- **GOOGL 및 선택 지지가 있는 나머지 종목:** 원래 지지 기간·구간, 무효화선, 최근 완료 주봉 종가·날짜, 일봉 가격·날짜, 손익비와 경고를 기록한다. 이전 주봉 당시 지지가 이미 존재했다는 근거가 없으면 실제 과거 이탈 사건이라고 확정하지 않는다.
- **가치평가:** 원래 지표 상태·원래 B2에 전달된 지표 목록·저장된 `metric_asof`/`retrieval_timestamp`를 확인한다. PBR이 표시됐지만 원래 평가 지표에서 빠졌는지 구분한다. C52의 과거 B2 결론을 C54 규칙으로 새로 수락하지 않는다.

필요한 파일이 실제 보관물에 없으면 그 파일과 진단 항목만 미확인으로 보고한다. 값을 재수집하거나 원래 모델 판단을 다시 생성해 채우지 않는다.
