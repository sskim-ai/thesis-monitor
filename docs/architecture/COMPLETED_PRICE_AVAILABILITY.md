# Completed Price Availability

REV58D is an offline, default-off fresh-shadow input repair. It does not enable
production delivery, collection, model execution, or a new investment policy.

## Ownership

- US completed-session price: `usa20590`, `/api/us/mrkcond`, exact security,
  exchange and target `base_dt`; existing `kiwoom-us-completed-session-price-v2`.
- US `usa06012`: chart/history/technical only. Its latest close is not fallback
  current-price authority. Invalid chart rows remain unchanged in raw evidence.
- Each future US subject has one mandatory, budgeted completed-close descriptor.
  Collection uses the existing sealed dispatcher and credential exchange.
- Freeze requires the exact, already-captured public Kiwoom documentation bytes
  via `--completed-close-documentation`. No documentation/provider fetch is added.

## Distinct States

`completed-current-price-state-v1` binds the source plan, request, every attempted
body, final receipt, observation time and decision scope. There is no fabricated
raw hash when transport produced no body.

`PLAN_GAP_REQUIRED_OWNER_NOT_REQUESTED` is precollection failure, not runtime
coverage. `UNAVAILABLE_SOURCE_ACQUISITION_FAILED` owns only the failed acquisition.
Successful response bodies can own target-row missing, integrity, or security/
session denials. Unknown implementation and provenance errors remain fail-stop.

`AVAILABLE` embeds the unchanged numeric completed-close owner. A denied price
travels separately from `chart-target-availability-v1`. Neither grants authority
to the other. Technical adjustment compatibility remains explicitly unproven.

## V1 And V2

Valid `current-price-context-v1`, `CurrentMultiple`, and
`current-fresh-valuation-view-v1` retain positive numeric price requirements.
`current-price-context-v2` and
`current-fresh-valuation-unavailable-price-v2` are companion representations:

- Price-arithmetic metrics stop at the exact typed price prerequisite. No
  denominator, corporate-action or share arithmetic is consumed on that path.
- Independently qualified native snapshots are context-only, with null numerator.
  Their existing identity, time, field, source quality and horizon owners still
  run. Missing local price grants no native metric entitlement.
- The price-availability fact records a source observation, never an economic
  price or price-as-of. Numeric registries contain no unavailable placeholder.

Core/A/Overall business permissions do not gain price or valuation facts.
Holder/v1 timing can remain unresolved. The artifact-only B2 input adapter maps
typed unavailable price to the existing mapping shape; frozen B2 prompt, schema,
policy and validator files are unchanged. Fundamental stance is not forced by
timing unavailability. The renderer emits an exact bound unavailable-price row.

Coverage uses the runtime price owner for required denial cells and reviewed
positive non-consumption proofs for unconsumed arithmetic prerequisites. Static
producer semantics never grant a current source decision. Missing native source
authority still fails closed independently; it is not relabeled a price denial.

## Replay Boundaries

The sealed REV58B generation has no mandatory completed-close slots and remains
diagnostic only. Repair does not requalify its 13 valid chart rows or repair TSM's
`HIGH_LT_CLOSE`. New fresh execution requires a separate generation and approval.

The test fixture `kiwoom_completed_close_official.json.gz` contains only the
previously sealed public API specification. Its uncompressed SHA-256 is
`42a7b3912c9d9588c83bdc2db7779c8d2e038703a2b5562e54ef46ae905cba79`.
Request/response tests use fictional wires or locally sealed historical evidence.
