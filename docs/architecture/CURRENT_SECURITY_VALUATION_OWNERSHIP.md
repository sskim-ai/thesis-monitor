# Current Security Valuation Ownership

REV25 local bounded repair. **Not a completed valuation qualification owner.**

The current acquired SEC companyfacts and OpenDART account-list projection
enumerates denominator candidates, but does not bind their class dimensions or
corporate-action adjustment basis to the monitored listing. A fresh response,
verified issuer, plausible ratio, or positive EPS is not that authority.

`security_valuation_basis.py` adds a typed denial receipt and an all-occurrence
inventory to the existing `CurrentValuationView`. The receipt binds security,
listing, currency, price basis/session, source hashes and inventory hash. Its
type intentionally cannot express QUALIFIED. No acquisition adapter currently
proves the missing basis. Caller-added split labels cannot expand authority.

Every current metric carries an independent `ownership_state`; the original
status field remains compatible with the existing renderer. Unavailable forward
estimates do not confer permission to create fPER. No valuation owner grants
Overall business direction or issuer-to-ADR transfer.

Candidate inventory preserves every raw occurrence identity, concept, filing,
start/end, unit/currency, statement basis, filing-focus label, revision relation,
and exclusion reasons. Filing focus does not classify duration. No interim EPS
annualization, value-based selection, missing-period reconstruction, or stale
fallback occurs. Raw source rows remain in the pre-existing denominator scope.

The old native adapter could qualify multiples with an absent share class by
falling back to local identity and had no corporate-action denominator owner.
That path now fails closed. Native values and negative EPS cannot become a
display number or N/M until an independently qualified basis adapter exists.
Changing synthetic positive expectations documents this hardening, not new
evidence of native/source-derived qualification.
