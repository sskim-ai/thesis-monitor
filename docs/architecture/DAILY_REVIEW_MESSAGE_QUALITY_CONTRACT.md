# Daily Review Message Quality Contract

The strict schema, numeric provenance, semantic ownership, valuation binding, final-language, and
runtime quality gates remain unchanged. A legacy immutable packet may be upgraded only in memory
to the current semantic-scope contract; the archived source is never rewritten.

Canonical numeric sentence normalization must update both rendered prose and every matching
`exact_text_span`. Single-number wrappers for current price and volume participation collapse to a
canonical sentence. Unsupported directional language about peak earnings multiples is removed
without changing the accepted decision.

Repeated secondary prose is suppressed only when the exact phrase occurs in at least three stock
reviews and a canonical fact or entity-specific section already owns the meaning. Thresholds are
not relaxed, numeric facts are not removed to evade validation, and ticker exceptions are
forbidden. Observer and holder prose must continue to express distinct decision variables.

Depositary-receipt underlying-share ratios are security-basis evidence, not assertions that the
listed instrument is common stock. Unavailable current-price risk/reward language is a canonical
structured state and may repeat without being treated as analytical prose duplication.
