# Family-Filtered Confluence

## Pipeline

`family-filtered-confluence-v1` enforces this order:

```text
validated ambiguity set
-> family dependency consensus
-> remove materially variant Fib
-> deterministic SR plus eligible Fib
-> rebuild timeframe maps
-> rebuild cross-timeframe confluence
-> shadow render
```

Hiding an unstable label after zone calculation is not allowed. Every retained Fib source carries
family, method, degree, consensus-set ID, optional equivalence-class ID, stability, target
timeframe, and canonical numeric provenance.

Zones containing exact-invariant or price-equivalent Fib are marked accordingly. A rendered
explanation cannot cite a removed family. Pivot, Bollinger, box, and prior-high/low sources remain
independent from wave ambiguity.
