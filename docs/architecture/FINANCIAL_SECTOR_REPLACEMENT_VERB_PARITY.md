# Financial-Sector Replacement Verb Parity

Contract: `korean-replacement-application-verb-v1`

Financial-sector exclusions remain claim-local and fail closed. A coordinated
industrial framework is a `CONTRASTIVE_REPLACEMENT` only when the same clause
contains all of the following:

1. An existing explicit exclusion or contrastive marker.
2. A recognized sector replacement concept.
3. A bounded affirmative analytical-application predicate.
4. No separate contradictory industrial-framework application.

The contrastive-marker and connective-exclusion paths share one Korean
application-verb family. Existing verbs remain supported and `해석한다` and
`해석합니다` have parity with `본다`, `판단한다`, and `평가한다`.

Negated interpretation, possibility language, and unrecognized replacement
concepts do not qualify. Clause boundaries, exclusion predicates, financial
completeness checks, FCF temporal semantics, and model-facing contracts are
unchanged.
