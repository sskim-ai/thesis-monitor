# Free Analyst Message Quality

## Contract

`entity-specific-synthesis-v1` extends the existing `message-quality-v2` gate. It does not
change evidence, numeric, semantic-ownership, or runtime quality thresholds.

For each stock, the gate extracts supported discriminators from current packet-derived prose and
the deterministic stored thesis. A non-Minimal candidate must preserve at least one supported
driver, validation metric, expectation burden, or unresolved proof. A candidate with no safely
supportable discriminator may use the existing Minimal renderer or fail closed to its deterministic
message.

The feature registry is semantic and ticker-independent. Current families include foundry advanced
nodes and wafer pricing, memory HBM/ASP/inventory, HPC billing and colocation economics, stablecoin
reserve and non-interest revenue, cloud investment conversion, biotech development/cash burn,
automotive margin/investment, defense delivery, and software/services economics. A feature in the
rendered text counts only when it also appears in that entity's allowed support set.

## Batch Repetition

`cross-message-synthesis-specificity-v1` classifies claim-bearing core and business sentences as:

- `GENERIC_SHARED`
- `ENTITY_SPECIFIC_SHARED_STRUCTURE`
- `ENTITY_SPECIFIC_UNIQUE`

The canary fails only the affected message when the same analytical claim crosses different
industry owners, a specific supported driver was available, and the claim has no supported
entity-specific discriminator. Similar structure within one industry remains valid when the
current entity owns the discriminator. This distinguishes analytical specificity from cosmetic
word variation.

Section ownership remains unchanged: business/earnings owns the company synthesis, positioning is
context only, and valuation does not inherit unsupported cash-flow multiples.
