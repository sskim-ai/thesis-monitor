# Explicit Current-Source Authority

`m12dk-current-source-authority-v1` is a user-approved eligibility policy, not an
inferred historical owner and not a desired investment decision. The supplied
JSON is preserved verbatim in `scripts/m12dk_current_source_authority_policy.json`.
Its byte digest is bound by the adapter. Unknown policy versions fail closed.

## Ownership

`scripts/m12dk_current_source_authority.py` emits the existing canonical authority
manifest. Canonical source-use projection, current-input binding, parent
intersection and final A/B validators remain unchanged. It consumes only frozen
stock/evidence packets; there is no fetch, model, persistence or delivery path.

Configured core thesis and macro exposure definitions may supply business
context, Pass-A archetype and valuation-tier evidence. They never independently
own Overall, Holder or New-Buyer current deterioration. Strengthen/weaken/
invalidation conditions are business context only, not proof of fulfillment.

Observed earnings may supply business context, Overall, archetype and tier only
after every exposed numerical field passes its existing financial-quality owner.
No Holder or New-Buyer use is newly granted. Every use absent from the explicit
allow set remains prohibited; Core/atomic membership never creates authority.

## Frozen Identity

Each owner input binds source generation, source packet ID, whole packet digest,
same-subject stock digest and exact evidence packet digest. Metadata must be an
unchanged row of that evidence packet and a member of the existing catalog.
Configured definitions must match the existing source renderer's projection of
the exact same-subject field. Macro shapes use the existing schema. Cosmetic
labels are not permission inputs, but their changed bytes require a new binding.

An enclosing frozen ticker is the identity basis, not an invented issuer ID.
No security-denominator verification is asserted by this source owner.

## Earnings Lineage

The receipt retains the frozen fact digest and field-level provider, source type,
period/dependencies, verification status, quality state and eligibility. Field
quality must equal the existing named field owner's record. A verified envelope
does not rescue a denied, critical, missing or unverified exposed field.

The adapter recognizes existing SEC companyfacts/full-statement, SEC foreign
filing/formal-or-provisional, and OpenDART statement provider paths. Unknown
providers remain unauthorized. Independently supported additional provider paths
require an explicit contract update; they are not inferred from a label.

The v2 financial-quality contract and verified lineage are required. OpenDART
additionally requires its v2 filing/row/flow-period lineage and v1 statement-basis
contract. Caution-usable remains marked as caution; it is not upgraded to fully
verified. Filing availability, period/as-of identities and field dependencies
must agree. No extrapolation, FX conversion or source repair occurs here.

Because the immutable evidence alias contains a whole earnings object, a mixed
safe/unsafe row is not granted decisive permission. Safe field paths remain in
the diagnostic receipt, but the unsafe alias is not partially elevated. A future
field-level source projection would need a separately frozen contract rather
than silently dropping an unsafe field or parent in this experiment.

## Restrictions And Gate

Existing quality, working-capital, expectations, market, identity and security
basis restrictions remain intact. Price, technical, positioning and valuation
families have an explicit A-visibility exclusion, enforced by the existing
whole-cohort preinference gate's optional restrictive filter. Their existing
downstream B/timing/valuation roles are untouched.

All claim uses are the intersection of all bound parent uses. The gate runs the
actual unchanged A builder, typed-quality filter and final-view binding for all
subjects. It withholds all request contexts if any subject fails. Actual 22/22
PASS is mandatory before A8; complete A8/22 is mandatory before B8.

No policy or semantic hotfix is permitted after the frozen inference experiment
begins. Source snapshot, blind pack, Core text/parents and A/B semantics remain
unchanged. Production, scheduler, Telegram, merge, push and deploy stay disabled.
