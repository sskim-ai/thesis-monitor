claims through the unchanged `validate_selected_refs` authority owner, separately
for `PASS_A_ARCHETYPE` and `PASS_A_VALUATION_TIER`. Premium retains its existing
additional premium-eligible constraint. Empty tier support removes resolved
branches but retains UNRESOLVED. Empty archetype support raises an explicit
branch-representation dependency; it never becomes an unconstrained string list.

source/execution identities, projection, binding and expectation. The current
input and consumed-view digests are checked before projection. Model-view hashes
use their existing serialization owner, including Unicode behavior.

the specific directional role with the typed quality evidence catalog; all refs
must belong to the same bound current source. Confidence-only typed quality refs
can be absent from narrative evidence without becoming directional evidence.

without current inputs fail closed. The active request capture now passes those
inputs; no semantic validator, source authority, prompt prose or B contract changes.

execution identity on the same source/blind, freezes all A8 requests before A1,
and uses homogeneous fresh A8. B8 requires complete A and the unchanged M12DO
pre-B gate. Independent batch-local failures are fail-soft, with zero retries;
systemic identity/runtime/security drift stops later calls. Historical A outputs
are diagnostic only. Full acceptance is required for sealed export; no reveal.
