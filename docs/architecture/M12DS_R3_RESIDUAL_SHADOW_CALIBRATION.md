# M12DS-R3 Rev1 Residual Shadow Calibration

Local, opt-in experiment only. Production modules, persistence, delivery, and
schedulers are unchanged. The instruction commit precedes implementation.
No source refresh, independent judgment input, or ticker-label targets.

## Ownership

- Current operating stress is separate from verified comparable deterioration.
  A single current loss is not an automatic SELL for any archetype; a mature
  business also needs a verified unexpected-loss baseline. This frozen cohort
  has no generic verified baseline or realized-impairment event adapter, so
  model wording cannot create those capabilities.
- Existing comparative issuer facts use the existing source-quality owner,
  which recomputes their exact period/basis/occurrences from frozen evidence.
  New nested comparative fixtures require matching typed period and basis.
- Confidence is orthogonal to direction. Established profitable/structural
  archetypes may retain BUY with LOW confidence. No expected ticker labels.
- Active adverse evidence without a verified fundamental discount takes
  precedence over generic valuation-unresolved WAIT for the new-buyer axis.
- Atomic claim array order owns capability serialization. Effect dictionary
  reordering is restored before invocation; semantic binding drift fails closed.

## Valuation and Market Boundaries

The exact frozen security and field-quality owner gates earnings valuation
entitlement. No blanket tag authorization or ADR denominator transfer.
Trailing EPS needs four compatible reported per-security quarters, as-of
availability, exact field values, arithmetic, and untainted field provenance.
Forward EPS additionally needs its own explicit share/currency/security and
future-period owner. A native forward multiple alone cannot provide that EPS.
Modeled-forward FY1 without a dated denominator owner remains excluded.

Field/prose eligibility and numeric-registry eligibility are different:
an exact field may authorize deterministic valuation calculation while the
source row remains unavailable for numeric prose. This patch changes no
numeric prose permissions. Every eligible method is audited by the existing
range materializer; directional method conflict remains unresolved.

Market facts are export-only. Source availability, exact ref, completed-session
date, row denial, and relative-parent arithmetic all apply. The actual frozen
US source labels proxy coverage available but dates its proxies after the last
completed session and marks those rows unavailable. The instruction's presumed
eligible proxies cannot be promoted from those bytes. Record each exclusion;
do not repair timestamps or refetch sources. KR current native rows stay separate.

## Runtime

Market2, Core8, A8, B8 are fresh requests under one implementation freeze.
Core22 is required before A; A22 before B. Independent batch-local failures
are collected without selective semantic reruns. Systemic failures stop.

Each logical request has at most two attempts. Only typed transient failures
with no final response permit the second identical attempt. Distinct runtime
namespaces preserve both receipts, exact prompt/schema/file/dependency hashes,
model `gpt-5.6-sol`, effort `xhigh`, and 1200-second timeout. Auth, certificate,
tool events, source drift, schema/semantic errors, and unknown exceptions are
not retried. The normal maximum is 26 processes, absolute maximum 52.

Offline shape fixtures never substitute for runtime responses. Acceptance
requires all 22 decisions online plus policy, source-use, range, and market
parity gates. Distribution or independent-review agreement is not a criterion.
Official CLI read-only/tool controls are verified; source-only inference is
not claimed as a certified sandbox property. Raw outputs remain local/sealed.
