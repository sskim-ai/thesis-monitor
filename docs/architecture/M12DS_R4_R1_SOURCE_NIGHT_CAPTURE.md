# M12DS-R4-R1 Source and Capture Boundary

Local-only successor to R4; main, deployment, recipient, scheduler and persistence remain unchanged.

## Source quality

`sec-business-field-quality-v1` preserves snapshot/valuation taint. A bound direct-field
receipt may isolate only a revenue occurrence conflict from independently verified
operating income. Taxonomy labels do not prove an issuer-total revenue role. Two
unresolved revenue concepts therefore remain unresolved; magnitude and ticker are not
selection inputs. Direction for such a repaired subject requires an exact same-filing,
same-currency/issuer/concept/duration prior-year comparison, never an absolute amount.
Old snapshots without the new receipt are not retrospectively stamped verified.

## Night ownership

`official-krx-night-market-consumption-v1` validates official owner, finality, date,
same-contract baseline, arithmetic, row identity and D/W/M before granting US recap
consumption for the next KR regular session. Generic R3 intake is unchanged. Completed
KR-close duplication remains prohibited. The existing intraday KR owner is unchanged.

## Accepted output

R3 decisions have three axes and do not contain the legacy maturity/change-condition
fields. `accepted-calibration-message-v1` is an explicit accepted-result variant at
`render_accepted_v2_production`, not a synthesized legacy candidate. It requires exact
packet, generation, accepted decision, deterministic ranges and claim-parent bindings.
The controller revalidates the original R3 policy and capability before constructing
that receipt. This is a trusted internal receipt, not a signature or an authorization
mechanism. Existing candidate/adjudication validation is unchanged.

`render_daily_digest` accepts a similarly bound market result through an opt-in
argument. US factual rendering remains owned by `render_us_full_market_message`.
No current production caller enables either new variant. Production exposure requires
the separately approved next phase.

The capture harness retains actual Telegram preparation/chunking and replaces only
`_send_chunk` with a local sink. Unsupported model prose numbers fail the existing
numeric provenance gate; they are not deleted or manually rebound. All range values
remain the deterministic materializer's output. No hidden reasoning is exported.

## Historical scope

`approved_scope_descendants.py` binds each migrated historical freeze to a finite
instruction-owned ancestor commit and its exact file bytes. Missing history, a changed
file, or an unlisted path fails closed. Mutation tests exercise every migrated scope
owner. No skip, xfail, broad path allowance or current-hash self-approval is used.

## Readiness

Offline gates precede repair freeze. A new source generation and all-subject source
gate precede model calls. R3 policy/prompt/schema remain frozen. A source or later gate
failure is reported as failure; historical diagnostics never count as current messages.
