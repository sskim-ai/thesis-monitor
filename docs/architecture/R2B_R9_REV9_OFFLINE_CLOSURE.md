## Current-Only Evidence

`reported-comparison-applicability-v1` separates a real quality record, proven
comparison non-applicability, and missing expected owner output. The positive
absence path currently requires replayed SEC quality receipts that explicitly
diagnose an absent prior occurrence. Current field lineage, freshness, normalized
hashes, security identity and context eligibility must all hold. Incompatible
prior data, transport errors and missing quality inputs remain fail-closed.

The non-applicable path emits no `financial_quality` fact. It emits an existing
earnings-family absolute context fact whose authority is CONTEXT only. The R7
absolute-current direction guard remains in force. Existing whole-decision
UNKNOWN_LIMIT validation, OBSERVE axes and the production payload preparation
boundary are reused. No neutral BUY:SELL score or verified financial-health
state is invented.

## Deterministic Inputs

The fresh technical baseline canonicalizes component object keys before the
native owner traverses them. It preserves arrays and source amounts. This closes
component-binding array/hash drift between in-memory inputs and JSON descriptors.
Legacy persisted owner serialization is unchanged.

Descriptor replay accepts explicitly hash-bound optional native valuation bytes
and receipts. Issuer bridge descriptors replay the ordinary-security acquisition,
official identity and source result before transferring issuer business facts.
They cannot transfer prices, technical context, EPS/BVPS or security multiples.

## Valuation

`CurrentMultiple` validates QUALIFIED, NOT_MEANINGFUL and UNAVAILABLE independently.
Hashes and currentness metadata are required for visible values. The existing
Finnhub stock/metric endpoint is replay-only: exact run, route, symbol, raw hash,
security hash and bounded receipt times are checked. Qualified fixture cases also
require explicit source as-of equal to the price session, explicit currency and
verified common-stock identity. Missing as-of/currency is not repaired by copying
the quote or request date. ForwardPE alone remains unavailable.

Native ratios are provider-owned values, not a claim that the current price
divided by the reported EPS reproduces that ratio. Their numerator has the explicit
role CURRENT_PRICE_CONTEXT_ONLY; entry-use and Overall-direction use are false.
Native denominator scope (TTM/provider-reported book) is not an independently
verified fiscal-end date. The exact native numerator/denominator derivation is
not qualified. Negative reported EPS produces N/M; PBR with no usable value stays
unavailable. No absent book denominator is invented.

Qualified display numbers are bound through the existing valuation numeric
registry (`trailing_pe`, `price_to_book`, `forward_pe`) to detached valuation facts,
metric receipts and the current view hash. Those facts are not added to the
directional evidence catalog.

Official SEC/OpenDART per-share denominators, an exactly owned forward horizon,
and a compatible historical distribution remain unconnected to this controller.
Existing parser output with unknown share basis is not upgraded. The synthetic
native positive cases prove conditional plumbing, not live provider coverage or
the complete valuation qualification matrix.
