# Sealed Cohort Owner Closure

REV9 is an opt-in offline proof, not production integration. Its only source
is the hash-verified REV8 capture. Existing acquisition defaults, source
policies, schedules, and message paths are unchanged.

## KR Consumer Completeness

`kiwoom-cross-section-consumed-pages-v1` qualifies the declared native
cross-section consumer. `ka20001` owns first-page scalar fields. `ka20009`
owns the unique target-session row used by the native session validator.
`ka20003` and flow APIs still require transport exhaustion. Unknown
dependencies, missing paths, and ambiguous target rows fail closed.

This does not claim that every provider series is complete. The original
observer receipt, continuation flags, and raw bytes remain unchanged. A new
post-capture aggregate must opt in and revalidate request identity, consumed
paths, session identity, and the native normalized output. The per-leaf
dependency ledger records both value inputs and session-validation inputs.

## Business Version Binding

`versioned-business-current-stock-binding-v1` reconstructs accepted reported
comparisons with the existing financial-quality and comparative-fact owners.
It checks the immutable version hash, current security/issuer identity,
original source graph, period, unit, provider, and eligibility at the frozen
REV8 cutoff. It never imports an older price packet or old PASS status.

Current price and technical components remain owned by the original fresh
stock receipts. The existing packet validator independently replays the
business version. The existing source-authority owner assigns only its
existing issuer-business permissions, never current-price or security-level
valuation authority. Issuer bridges retain their original accepted identity
receipt and prohibit per-share, valuation, and price/technical transfer.

Already-complete base packets remain byte-identical. A denied mixed financial
tuple stays denied when qualified comparison evidence is appended.

Persisted event reuse requires its own original acquisition and source-owned
event graph. A filing discovery record is not interchangeable with a missing
accepted reported business event. No event-type exception is introduced.

## Whole-Cohort Gate

All 22 current stock packets and their authority receipts must pass before
whole-source composition. Partial output is diagnostic only. No accepted
run seed, US/KR whole-source packet, or full authority graph may be produced
from a partial cohort. Component PASS is not complete-adapter qualification.

All replay commands deny network access. Report delivery to the user's
iCloud location is a separate post-sealing artifact operation.
