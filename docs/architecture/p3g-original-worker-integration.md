same-plan page-chain validation. Provider reauthentication compatibility has not
been proved. This implementation deliberately does NOT claim to solve that mode.

and generation must match the canonical authority graph. Missing binding,

optional-night availability produce typed MISSING_REQUIRED_COMPONENT denials.

authenticated component-to-graph execution branch remains an explicit code/test
gap. Denial inventory tests are not proof that all Provider parents were supplied.
