# Pending read-only local Source capture

The explicit task adapter can select `record_backend_local_scope` after an
actual bounded user approval. This is separate from the unchanged strict
operator/exclusivity API. It checks the original participating CLI session,
Global Lane, local lock and persistent STOP. It does not attest remote devices.
The original lane still serializes each physical request and latches failures.
No activation, daemon, scheduler or production permission is introduced.

One pending Parent may select a nonempty subset of authenticated registrations.
Unknown subjects and changed identities remain rejected. Original source
compilation, maximum 20 physical attempts, isolated Worker handshake, transport,
two replays and Source-only consumers remain in use.

Pending W/M receipts retain the original period proof's evidence state rather
than overwriting it with a daily label. Pending registration is recorded
separately. Cold replay must use the authenticated scoped dispatcher plan and
the original W/M raw/parser context. Cold replay cannot resurrect a live Owner.

Real acquisition and qualification are distinct. Short history, invalid OHLC,
unbound close documentation, missing Market parents or a persistent STOP must
remain explicit. Source-only data grants no technical, valuation, financial,
economic, D01/D02, Native, model or send authority. Default startup stays OFF.
