# 주식 차트분석·기업가치 분석 통합 지식

## 0. 문서 목적과 사용 원칙

이 문서는 다음 두 가지를 하나의 분석 체계로 결합한다.

1. **차트분석**: 현재 가격 위치, 지지/저항/박스권, Bollinger 상단선, OHLC, 거래량/거래대금, RSI, MACD, Elliott/Fibonacci, 수급을 이용해 **어디서 신규매수하고 어디서 판단을 무효화할지** 정한다.
2. **기업가치 분석**: 최근 5년 실적, ROE, ROA, PER, PBR, fair PBR, sector fair PBR, 현금흐름, CAPEX, FCF, owner earnings, 주주환원, 업황을 이용해 **그 가격을 지불할 만큼 기업의 수익성과 현금창출력이 좋은지** 판단한다.

최종 목적은 상승/하락을 맞히는 것이 아니라 아래 질문에 답하는 것이다.

- 현재 가격은 싸게 살 수 있는 위치인가, 추격 위치인가?
- 위쪽 저항까지 기대수익이 충분한가?
- 아래쪽 방어선은 어디인가?
- 그 가격이 깨지면 무엇이 틀린 것인가?
- 거래량과 외국인/기관 수급은 가격을 확인하는가?
- 기업가치와 업황은 현재 가격을 정당화하는가?
- 신규매수자는 기다려야 하는가, 분할 접근 가능한가?
- 보유자는 유지해야 하는가, 일부 비중을 관리해야 하는가?

### 0.1 가장 중요한 원칙

**좋은 기업, 좋은 차트, 좋은 매수가격은 서로 다른 판단이다.**

따라서 다음과 같은 결론을 허용한다.

- 기업은 좋지만 현재 가격은 비싸다.
- 차트는 강하지만 신규매수 손익비는 나쁘다.
- PBR은 낮지만 ROE가 낮아 가치함정 가능성이 있다.
- ranking은 높지만 신규매수 후보는 아니다.
- 장기 상단선 위지만 자동 매도 구간은 아니다.
- 신규매수자는 기다려야 하지만 보유자는 유지할 수 있다.

### 0.2 단일 신호 판단 금지

다음 신호 하나만으로 매수/매도를 결정하지 않는다.

- Bollinger 상단선 돌파만으로 매수
- 장기 상단선 위라는 이유만으로 매도
- RSI가 높아서 매도
- RSI가 낮아서 매수
- 외국인 순매수만으로 매수
- ranking 상위라서 매수
- PER이 낮아서 저평가
- PBR이 낮아서 저평가

항상 아래를 결합한다.

**가격 + Bollinger + 지지/저항 + OHLC + 거래량/거래대금 + 수급 + 기업가치 + 업황 + 손익비**

### 0.3 문서 내 규칙 구분

- **[고정 규칙]**: 기존 지식/보고서 기준에서 반드시 유지할 내용
- **[권장 구현]**: 기존 기준을 실제 코드로 재현하기 위해 구체화한 계산 방식
- **[예시]**: 산식 이해를 위한 실전 예

기존 데이터 파이프라인이나 stock_screener가 이미 정확한 계산식을 가지고 있다면 **기존 계산식을 우선**하고, [권장 구현]은 재현/검증용으로 사용한다.

# PART I. 전체 분석 프레임

## 1. 분석 순서

종목별 판단은 다음 순서를 기본으로 한다.

1. 현재 가격 위치
2. 지지대 / 저항대 / 박스권
3. Bollinger 상단선과의 관계
4. OHLC / 캔들 구조
5. 거래량 / 거래대금
6. RSI / MACD / 중장기 모멘텀
7. 외국인 / 기관 / 개인 수급
8. Elliott / Fibonacci
9. 업황 / 시장 기대 / 리스크
10. 기업가치
11. 신규매수 손익비
12. 보유자 관리 기준
13. 무효화 가격
14. 최종 판단

## 2. 신규매수자와 보유자를 분리하는 이유

### 2.1 신규매수자

신규매수자의 질문은 다음이다.

> 지금 새 돈을 넣었을 때 손익비가 좋은가?

필수 항목:

- 1차 매수 가격대
- 2차 매수 가격대
- 확인 매수 가격대
- 추격 금지 가격대
- 무효화 가격
- 목표/저항까지 상방 여유
- 무효화까지 하방 위험
- 거래량 조건
- 수급 조건
- 기업가치 안전마진

### 2.2 보유자

보유자의 질문은 다음이다.

> 이미 가진 수량을 어디까지 유지하고 어디서 관리할 것인가?

필수 항목:

- 유지 가능한 가격
- 1차 비중 조절 가격
- 강한 관리 가격
- trailing 기준
- 장기 상단선 재이탈 여부
- 거래량 증가 윗꼬리 여부
- 외국인/기관 분산 여부
- 기업가치 훼손 여부

### 2.3 결론 분리 예

- 신규매수: 현재가 추격 금지
- 보유자: 주요 지지 유지 시 보유
- 1차 관리: 장기 저항 접근 시 일부 비중 조절
- 무효화: 핵심 주봉 지지 이탈 시 보유 논리 재검토

# PART II. 차트분석 방법 — 계산식·알고리즘 수준

## 3. 입력 데이터

### 3.1 기본 raw OHLCV

각 timeframe에 최소 다음 데이터가 필요하다.

- datetime
- open
- high
- low
- close
- volume
- trading_value

가능하면 일봉/주봉/월봉 각각 충분한 기간을 확보한다.

기본 raw 조회 정책:

- periods: daily, weekly, monthly
- count: 300
- adjusted: true
- include_indicators: true

### 3.2 timeframe 변환 [권장 구현]

일봉에서 직접 주봉/월봉을 재생성할 경우:

#### 주봉

- Open = 해당 주 첫 거래일 시가
- High = 해당 주 최고가
- Low = 해당 주 최저가
- Close = 해당 주 마지막 거래일 종가
- Volume = 해당 주 거래량 합
- Trading Value = 해당 주 거래대금 합

#### 월봉

- Open = 해당 월 첫 거래일 시가
- High = 해당 월 최고가
- Low = 해당 월 최저가
- Close = 해당 월 마지막 거래일 종가
- Volume = 해당 월 거래량 합
- Trading Value = 해당 월 거래대금 합

주봉 기준일은 데이터 소스와 일치시켜야 한다. 구현 시 금요일 기준 또는 거래소 주차 기준 중 하나를 고정한다.

## 4. Bollinger 상단선

## 4.1 기본 공식

[권장 구현]

일반적인 상단선 계산은 다음과 같다.

\[
Upper_t(n,k) = SMA_n(C_t) + k \times SD_n(C_t)
\]

- \(C_t\): 종가
- \(SMA_n\): 최근 n봉 단순이동평균
- \(SD_n\): 최근 n봉 종가 표준편차
- \(k\): 표준편차 배수

기존 indicator 엔진에서 동일한 값이 제공되면 재계산보다 제공값을 우선한다.

## 4.2 사용 중인 상단선 설정 [고정 규칙]

| 명칭 | 설정 | 의미 |
|---|---:|---|
| 3개월 상단선 | 36 / 1.541 | 단기 탄력, 단기 재가속 |
| 5개월 상단선 | 60 / 1.541 | 중기 추세 확장 |
| 6개월 상단선 | 50 / 2.25 | 중기 추세 확장 |
| 12개월 상단선 | 144 / 1.541 | 1년 흐름 상단, 중장기 레짐 |
| 24개월 상단선 | 288 / 1.541 | 장기 사이클 높은 가격 위치 |
| 54개월 상단선 | 300 / 3.33 | 장기 극단 상단권, 보유자 관리 |

보고서에는 `36/1.541` 같은 설정값 대신 **3개월 상단선**처럼 이름을 쓴다.

## 4.3 기간별 의미

### 3개월 상단선

- 단기 탄력
- 단기 반등의 재가속 여부
- 조정 후 첫 번째 회복 기준

현재가가 3개월 상단선 아래라면 장기 상승 구조가 살아 있더라도 **단기 재가속은 미확인**으로 본다.

### 5개월/6개월 상단선

- 중기 추세 확장
- 돌파 후 눌림 지지 전환 여부
- 중기 상승이 단순 반등인지 새로운 추세인지 구분

가장 선호하는 순서는 다음이다.

**3개월 회복 → 5개월/6개월 회복 → 눌림 → 상단선 지지 → 재상승**

### 12개월 상단선

- 중장기 레짐 전환
- 돌파 후 안착 여부
- 재이탈 시 레짐 신뢰도 약화

### 24개월 상단선

- 장기 사이클의 높은 가격 위치
- 신규매수 손익비 악화 가능성
- 돌파 후 지지 전환 시 장기 강세 레짐

### 54개월 상단선

- 장기 극단 상단권
- 보유자 비중 관리
- 자동 매도선은 아님
- 돌파 안착 후 지지 전환이면 대형 추세 확장 가능

## 4.4 Bollinger 상태 분류

### A. 초기 회복

조건 예:

- 현재가 > 3개월 상단선
- 현재가 < 5개월/6개월 상단선

판단:

- 단기 반등은 확인
- 중기 추세 전환은 아직 미확인

### B. 중기 확장

조건 예:

- 현재가 > 3개월
- 현재가 > 5개월
- 현재가 > 6개월
- 눌림에서 이 선들이 지지 역할

판단:

- 중기 추세 확장 가능성 상승

### C. 장기 레짐 확장

조건 예:

- 현재가 > 12개월/24개월
- 종가 안착
- 눌림에서 장기 상단선 지지
- 거래량과 수급 유지

판단:

- 장기 상승 레짐 가능성

### D. 과열 경계

조건 예:

- 현재가와 3개월/5개월/6개월 상단선 이격 과대
- 단기간 24개월/54개월 상단선까지 확장
- 거래량 급증
- 긴 윗꼬리
- 외국인/기관 약화
- 개인 추격 증가

판단:

- 차트는 강해도 신규매수 가격은 불리할 수 있음

## 5. 현재가와 상단선의 거리 계산

각 상단선에 대해 현재가의 상대 위치를 계산한다.

\[
Distance\% = \frac{Current - Upper}{Upper}\times 100
\]

예:

- 현재가 105,000원
- 3개월 상단선 100,000원

\[
Distance = 5.0\%
\]

해석:

- +값: 현재가가 상단선 위
- -값: 현재가가 상단선 아래

단, 이격이 크다고 자동 매도하지 않는다. 이격은 **추격 손익비와 과열 위험을 평가하는 보조값**이다.

## 6. 가격순 정렬 규칙

[고정 규칙]

Bollinger 표는 반드시 실제 가격순으로 정렬한다.

### 6.1 상단선 배열

1. 모든 Bollinger 상단선을 가격값으로 수집
2. 현재가도 하나의 가격 요소로 삽입
3. 높은 가격부터 낮은 가격 또는 보고서 규칙에 맞는 한 방향으로 정렬
4. 현재가는 실제 위치에 둔다

현재가를 무조건 첫 번째/마지막에 넣지 않는다.

### 6.2 지지 후보

- 현재가 이하의 요소만 사용
- 현재가와 가까운 순
- 현재가 아래 Bollinger 상단선은 지지 전환 후보로 포함
- 박스 내부면 박스 하단을 지지 후보로 반영

### 6.3 저항 후보

- 현재가 이상의 요소만 사용
- 현재가와 가까운 순
- 현재가 위 Bollinger 상단선은 회복/저항 후보
- 박스 내부면 박스 상단을 저항 후보로 반영

# 7. Pivot 기반 지지대·저항대

## 7.1 기본 lookback [고정 규칙]

- 일봉: 최근 300봉
- 주봉: 최근 60봉
- 월봉: 최근 60봉

## 7.2 pivot 판정 [고정 규칙]

### pivot low

시점 \(t\)의 저가가 좌우 일정 봉의 저가보다 낮으면 pivot low 후보로 본다.

\[
L_t = \min(L_{t-w}, ..., L_t, ..., L_{t+w})
\]

기본 좌우 폭:

- 일봉: 3봉
- 주봉: 2봉
- 월봉: 1-2봉

### pivot high

\[
H_t = \max(H_{t-w}, ..., H_t, ..., H_{t+w})
\]

동일한 좌우 폭을 사용한다.

## 7.3 인접 pivot 가격대 병합 [고정 개념 + 권장 구현]

의미 있는 고점/저점이 비슷한 가격에 반복되면 하나의 zone으로 합친다.

허용폭:

- 일봉: ±1.5%-2.0%
- 주봉: ±2.0%-2.5%
- 월봉: ±2.5%-3.5%

변동성이 큰 종목은 다음 허용폭을 사용할 수 있다.

\[
Tolerance = \max(Price \times tolerance\_pct,\ ATR \times 0.5)
\]

### 권장 병합 절차

1. pivot 가격을 낮은 가격부터 정렬
2. 현재 묶음의 대표가격과 다음 pivot의 차이를 계산
3. 차이가 허용폭 이내면 같은 가격대로 합침
4. 허용폭을 넘으면 새로운 가격대로 분리
5. 최종 zone의 하단/상단을 구함
6. 지나치게 넓은 zone은 timeframe별 폭 제한을 적용

## 7.4 zone 폭 제한 [고정 규칙]

- 일봉 지지/저항: 4%-6%
- 주봉 지지/저항: 6%-8%
- 월봉 지지/저항: 8%-12%
- 일봉 박스: 8%-12%
- 주봉 박스: 10%-15%
- 월봉 박스: 15%-20%

## 7.5 지지/저항 우선순위

[권장 구현]

모든 zone을 보고서에 넣지 않는다. 현재 의사결정에 필요한 구간을 우선한다.

우선순위:

1. 현재가와 가까운 zone
2. 최근에도 가격 반응이 있었던 zone
3. 일봉/주봉/월봉이 겹치는 zone
4. Bollinger 상단선과 겹치는 zone
5. Fibonacci 되돌림과 겹치는 zone
6. 최근 돌파/이탈이 발생한 가격대
7. 무효화 기준으로 사용 가능한 zone

# 8. 박스권

박스권은 매수자와 매도자가 균형을 이루는 가격 영역이다.

### 박스 내부

현재가가 박스 내부라면 방향 예측보다 다음을 본다.

- 박스 하단 지지
- 박스 상단 저항
- 거래량 감소 여부
- 상단 돌파 시 거래량 증가
- 하단 이탈 시 거래량 증가

### 강한 저항으로 변하는 경우

현재가가 박스 하단 아래에 있고 최근 시가/종가가 박스 하단을 회복하지 못한다면 기존 박스는 상방의 강한 공급 영역으로 바뀔 수 있다.

# 9. OHLC 캔들 분석

## 9.1 기본 파생값

한 봉의 가격 range:

\[
Range = H-L
\]

몸통:

\[
Body = |C-O|
\]

몸통 비율:

\[
BodyRatio = \frac{|C-O|}{H-L}
\]

종가 위치:

\[
ClosePosition = \frac{C-L}{H-L}
\]

윗꼬리:

\[
UpperWick = H-\max(O,C)
\]

윗꼬리 비율:

\[
UpperWickRatio = \frac{UpperWick}{H-L}
\]

아랫꼬리:

\[
LowerWick = \min(O,C)-L
\]

아랫꼬리 비율:

\[
LowerWickRatio = \frac{LowerWick}{H-L}
\]

`H == L`이면 0으로 나누지 않도록 예외처리한다.

## 9.2 range %

기존 데이터 엔진에 정의가 있으면 그 정의를 사용한다.

[권장 구현]

\[
RangePct = \frac{H-L}{PrevClose}\times 100
\]

## 9.3 종가 위치 해석

대략적 해석:

- 0.65 이상: 고가권 마감
- 0.35 이하: 저가권 마감
- 0.35-0.65: 중간 영역

이 값만으로 판단하지 않고 몸통, 꼬리, 거래량을 함께 본다.

### 예

종가 위치 0.80 + 큰 양봉 + 거래량 증가:

- 매수세 우위
- 저항 돌파 시 신뢰도 상승

종가 위치 0.20 + 큰 음봉 + 거래량 증가:

- 매도세 우위
- 지지 이탈이면 추세 훼손 가능성 상승

긴 아랫꼬리 + 종가 고가권:

- 장중 저가 매물을 흡수
- 거래량이 너무 적으면 단순 반등일 수 있음

긴 윗꼬리 + 거래량 급증:

- 고가권 매물 출회
- 장기 저항 근처라면 분산 가능성 확인

# 10. 거래량과 거래대금

## 10.1 상대 거래량

기존 indicator 엔진의 정의를 우선한다.

일반화하면:

\[
VolumeRatio = \frac{CurrentVolume}{ReferenceAverageVolume}
\]

## 10.2 상대 거래대금

\[
TradingValueRatio = \frac{CurrentTradingValue}{ReferenceAverageTradingValue}
\]

지식 기준에는 평균 산정기간이 고정되어 있지 않으므로, 코드 구현에서는 screener와 같은 기준을 반드시 사용한다.

재현용으로 별도 구현할 때만 예를 들어 20봉 평균을 쓸 수 있다.

## 10.3 기본 해석

- 0.8 이하: 평소보다 거래가 줄어든 상태
- 0.8-1.1: 평균 부근
- 1.2 이상: 의미 있는 거래 증가 확인에 자주 사용하는 기준
- 2.0 이상: 강한 이벤트성 거래 가능성, 가격 반응을 함께 확인

## 10.4 가격과 결합

### 지지대에서 거래량 감소

- 매도 압력이 줄어드는 눌림일 수 있음
- 외국인/기관이 유지되면 1차 접근 확률 상승

### 저항 돌파 + 거래량 증가

- 실제 참여 자금 유입
- 종가 안착이 동반되면 확인 매수 신뢰도 상승

### 지지 이탈 + 거래량 증가

- 단순 변동보다 매도 압력 확대
- 무효화 가능성 상승

### 고점 윗꼬리 + 거래량 급증

- 공급 증가
- 장기 상단권이면 보유자 비중 관리 신호가 될 수 있음

# 11. RSI

기존 indicator 엔진 제공값을 우선한다.

[권장 구현: Wilder RSI]

\[
RS = \frac{AverageGain_n}{AverageLoss_n}
\]

\[
RSI = 100 - \frac{100}{1+RS}
\]

보통 n=14를 사용하되 기존 시스템 설정과 일치시킨다.

### 해석 원칙

- RSI 70 이상이라고 자동 매도하지 않는다.
- RSI 30 이하라고 자동 매수하지 않는다.
- 가격 위치와 거래량을 같이 본다.

예:

- RSI 75 + 54개월 상단권 + 거래량 급증 윗꼬리 → 과열 관리 강화
- RSI 75 + 장기 상단선 돌파 + 거래량 증가 양봉 + 외국인/기관 동반 → 추세 확장 가능
- RSI 25 + 주요 지지 이탈 + 거래량 증가 음봉 → 싸졌다고 보기보다 추세 훼손 우선
- RSI 30 부근 + 장기 지지 + 거래량 감소 + 수급 유지 → 눌림 후보

# 12. MACD

## 12.1 기본 공식

\[
MACD_{a,b} = EMA_a(C) - EMA_b(C)
\]

\[
Signal = EMA_s(MACD)
\]

\[
Histogram = MACD-Signal
\]

## 12.2 사용 가능한 주요 조합

- 일반 MACD
- MACD_OSC_20_40_9
- MACD_OSC_40_80_9
- MACD_OSC_80_160_9
- MACD_OSC_320_640_9

이 조합은 단기부터 매우 장기까지 모멘텀을 분리해서 본다.

## 12.3 해석

### 0선 위

중심 추세가 상승 우위.

### 0선 아래

중심 추세가 약세 우위.

### 0선 회복

조정 이후 추세 회복 가능성.

### Histogram 개선

음수 폭이 줄거나 양수 폭이 커지면 모멘텀 개선.

### Histogram 악화

양수 폭이 줄거나 음수 폭이 확대되면 모멘텀 약화.

### 다중 MACD 조합

예:

- 20/40/9 상승 전환
- 40/80/9 상승 전환
- 80/160/9 0선 위 유지
- 320/640/9 장기 상승 유지

라면 단기 반등이 장기 추세 안에서 재가속될 가능성이 높다.

반대로 단기 MACD만 개선되고 장기 MACD가 계속 하락하면 기술적 반등 가능성을 우선한다.

# 13. ATR

[권장 구현]

True Range:

\[
TR_t = \max(H_t-L_t,\ |H_t-C_{t-1}|,\ |L_t-C_{t-1}|)
\]

ATR:

\[
ATR_n = WilderAverage(TR,n)
\]

용도:

- 변동성 큰 종목의 zone 허용폭
- 무효화 버퍼
- 손절폭 현실성 확인
- 서로 다른 종목의 절대 가격 변동 비교

# 14. Elliott Wave

Elliott는 예측을 강제하는 도구가 아니라 **가격 구조를 시나리오화하는 보조 도구**다.

## 14.1 원칙

- 1-2-3-4-5를 억지로 맞추지 않는다.
- raw OHLCV swing을 우선한다.
- 최근 저점을 기계적으로 1파 시작으로 잡지 않는다.
- major base low, breakout start, first higher-low를 비교한다.
- 카운트가 애매하면 신뢰도를 낮춘다.

## 14.2 상승 impulse 후보

### 1파 시작 후보

- 장기 하락 후 의미 있는 저점
- 이후 higher high가 형성됨
- 거래량/수급 전환이 동반되면 신뢰도 상승

### 1파 고점

- 1파 시작 이후 첫 의미 있는 swing high
- 이후 조정이 실제로 발생한 고점

### 2파 저점

- 1파 고점 이후 되돌림
- 1파 시작 저점을 훼손하지 않아야 함

### 3파 고점

- 2파 이후 강한 추세 확장
- 거래량 확대 또는 Bollinger 상단선 확장이 동반되면 신뢰도 상승

### 4파 조정

- 3파 이후 눌림
- 1파 고점과 겹침이 지나치면 impulse 신뢰도 하락

### 5파 후보

- 4파 이후 전고점 회복/신고가 시도

## 14.3 카운트 신뢰도

### 높음

- swing 구조가 명확
- 거래량이 파동 구조와 정합
- Bollinger 추세 확장 동반
- 핵심 지지 훼손 없음

### 보통

- 큰 구조는 보이나 중간 파동이 일부 겹침
- 거래량 확인 부족

### 낮음

- 가격 겹침이 많음
- pivot 선택에 따라 카운트가 크게 달라짐
- 상장 기간이 짧음
- raw data가 충분하지 않음

# 15. Fibonacci

## 15.1 상승 파동의 되돌림

기준 저점 \(L\), 고점 \(H\)일 때:

\[
Retracement(r)=H-r(H-L)
\]

사용:

- 0.382
- 0.5
- 0.618

예:

\[
0.5\ 되돌림 = H-0.5(H-L)
\]

## 15.2 현재 보고서식 확장

기준 저점 \(L\), 고점 \(H\)를 이용해:

\[
Extension(e)=L+e(H-L)
\]

사용:

- 0.618
- 1.0
- 1.618
- 2.618

이 값은 추격 매수 목표가가 아니라 **보유자 관리/저항 확인 기준**으로 쓴다.

## 15.3 Fibonacci 단독 판단 금지

다음이 겹칠수록 신뢰도가 올라간다.

- Fibonacci 되돌림
- 일봉/주봉 지지
- Bollinger 상단선 지지 전환
- 과거 돌파 가격
- 거래량 감소
- 수급 유지

# 17. 손익비

## 17.1 기본 계산

\[
Upside = TargetResistance - CurrentPrice
\]

\[
Downside = CurrentPrice - InvalidationPrice
\]

\[
RR = \frac{Upside}{Downside}
\]

## 17.2 해석

- 2 이상: 매력적
- 1-2: 조건부
- 1 이하: 현재가 추격 불리

단, 숫자만으로 매수하지 않는다.

예를 들어 RR이 3이어도:

- 위 저항이 비현실적으로 멀거나
- 현재 지지가 약하거나
- 수급이 distribution이거나
- 기업가치가 현재 가격을 정당화하지 못하면

신규매수를 보류한다.

# 18. 무효화 가격

무효화 가격은 단순한 정률 손절선이 아니다.

정의:

> 내가 세운 상승/눌림/지지 시나리오의 핵심 전제가 깨지는 가격

주요 근거:

- 주요 일봉/주봉 지지 하단
- 돌파 후 지지 전환된 Bollinger 상단선
- Elliott 4파 후보 저점
- 박스 하단
- 장기 레짐 기준선

## 18.1 [권장 구현] 버퍼

기존 screener 규칙이 없을 때만 다음과 같은 구조적 버퍼를 사용할 수 있다.

\[
Buffer = \max(ATR\times 0.5,\ CurrentPrice\times pctBuffer)
\]

장기 timeframe일수록 pctBuffer를 더 넓게 두되, 종목 변동성과 tick size를 반영한다.

무효화는 단순 장중 이탈보다 **종가 이탈 + 거래량 증가 + 수급 악화**가 동반될 때 신뢰도가 높다.

```python
            timeframe=tf_name,
        )

        # 6) classify support / resistance / box
        support = nearest_support(zones, current=df.close.iloc[-1])
        resistance = nearest_resistance(zones, current=df.close.iloc[-1])
        box = detect_balance_box(zones, df)

        # 7) insert current price into real price ordering
        ordered_bands = sort_with_current_price(
            current=df.close.iloc[-1],
            bands=bands,
        )

        # 8) Elliott/Fibonacci
        swings = detect_major_swings(df)
        elliott = build_tentative_wave_count(swings)
        fib = calc_fibonacci(elliott)

        # 9) timeframe judgment
        result[tf_name] = combine(
            bands,
            candle,
            volume_ratio,
            value_ratio,
            rsi,
            macd,
            support,
            resistance,
            box,
            elliott,
            fib,
        )

    # 10) supply-demand
    supply = classify_supply_demand(flows)

    # 11) multi-timeframe synthesis
    structure = synthesize_timeframes(result, supply)

    # 12) entry/invalid/holder levels
    levels = build_action_levels(structure)

    # 13) risk-reward
    rr = calc_rr(
        current=levels.current,
        target=levels.first_resistance,
        invalidation=levels.invalidation,
    )

    return {
        "timeframes": result,
        "supply": supply,
        "levels": levels,
        "rr": rr,
        "decision": final_decision(structure, levels, rr),
    }
```

- 불황에도 유지되는지

---

# 24. ROE

## 24.1 기본 공식

정밀하게는 평균 자기자본을 사용한다.

\[
ROE = \frac{NetIncomeAttributableToOwners}
{(BeginningEquity + EndingEquity)/2}
\]

가능하면 지배기업 소유주지분 순이익과 지배기업 소유주지분 자기자본을 맞춘다.

## 24.2 사용자 기준

- ROE 10% 이상 지속성을 선호
- 단년도 고ROE보다 여러 해 지속성이 중요

## 24.3 높은 ROE의 질 확인

높은 ROE가 다음 원인인지 확인한다.

- 본업 경쟁력
- 고마진
- 자산회전
- 부채 확대
- 자사주 소각으로 자본 축소
- 일회성 이익
- 업황 peak

높은 ROE라도 부채/일회성 이익 의존이면 할인한다.

---

# 25. ROA

\[
ROA = \frac{NetIncome}{AverageTotalAssets}
\]

평균 총자산:

\[
AverageAssets = \frac{BeginningAssets+EndingAssets}{2}
\]

일반 제조업에서 자산효율을 확인하는 데 유용하다.

사용자 선호 기준은 대체로 ROA 7% 이상이지만, 금융업은 자산구조가 다르므로 같은 잣대를 기계적으로 적용하지 않는다.

---

# 26. PER

\[
PER = \frac{Price}{EPS}
\]

또는:

\[
PER = \frac{MarketCap}{NetIncome}
\]

PER 해석 전 확인:

- 현재 EPS가 정상 이익인가?
- 업황 peak EPS인가?
- 일회성 이익이 포함됐는가?
- 감가상각/충당금이 정상 수준인가?
- 향후 이익 감소 가능성이 큰가?

특히 반도체, 화학, 조선 등 사이클 산업은 **PER이 가장 낮을 때 업황 고점일 수 있다.**

---

# 27. PBR

\[
PBR = \frac{Price}{BPS}
\]

또는:

\[
PBR = \frac{MarketCap}{Equity}
\]

낮은 PBR만으로 저평가라고 판단하지 않는다.

예:

- PBR 0.6배
- ROE 3%
- 자본비용 11%

이라면 장기 discount가 합리적일 수 있다.

반대로:

- ROE 15%
- 안정적 현금흐름
- 자사주 소각
- 높은 주주환원

이면 PBR 1배 이상도 충분히 정당화될 수 있다.

---

# 28. BPS

기본:

\[
BPS = \frac{EquityAttributableToOwners}{SharesOutstanding}
\]

주의:

- 우선주가 존재하면 보통주와 우선주의 경제적 권리가 완전히 같지 않을 수 있다.
- 자기주식을 발행주식수에서 제외할지 회계/데이터 공급자 기준을 일치시켜야 한다.
- vendor PBR과 직접 비교할 때는 vendor BPS 정의를 확인한다.

---

# 29. fair PBR

## 29.1 기본 공식 [고정 규칙]

\[
fair\_pbr =
\left(
\frac{1+ROE}{1+discount\_rate}
\right)^N
\]

기본:

- discount_rate = 0.11
- N = 3

ROE는 소수로 입력한다.

예:

- ROE 12% → 0.12
- discount rate 11% → 0.11

## 29.2 의미

ROE가 요구수익률보다 높으면 fair PBR이 1배 위로 올라갈 수 있다.

ROE가 요구수익률보다 낮으면 fair PBR은 1배 아래로 내려갈 수 있다.

## 29.3 중요한 한계

이 공식은 단순화된 자본효율 모델이다.

다음을 별도로 반영해야 한다.

- ROE의 지속성
- 성장률
- 배당/자사주
- 부채
- 업황
- 무형자산
- 경쟁우위
- 이익 변동성
- 장기 CAPEX
- sector 특성

따라서 fair PBR은 **절대 적정가가 아니라 가치 판단의 중심축 하나**다.

---

# 30. expected return

## 30.1 기본 공식 [고정 규칙]

\[
expected\_return =
\frac{1+ROE}{PBR^{1/N}} - 1
\]

기본 N=3.

## 30.2 의미

현재 PBR이 높아질수록 같은 ROE에서 기대수익률은 낮아진다.

ROE가 높아질수록 같은 PBR에서 기대수익률은 높아진다.

따라서:

- 좋은 회사도 너무 비싸게 사면 기대수익률이 낮아질 수 있다.
- 낮은 PBR도 낮은 ROE가 지속되면 매력이 없을 수 있다.

# 32. 영업현금흐름

\[
OCF = CashFlowFromOperations
\]

확인:

- 순이익과 같은 방향인가?
- 순이익보다 현금이 지속적으로 적은가?
- 운전자본 증가가 현금을 잡아먹는가?
- 반복적인 충당금/비현금 비용이 큰가?

# 33. CAPEX와 FCF

단순화:

\[
FCF = OCF - CAPEX
\]

확인:

- 유지 CAPEX와 성장 CAPEX 구분
- CAPEX 증가가 미래 ROIC를 높일지
- 투자 후 실제 매출/이익이 따라오는지

FCF가 음수라도 성장 CAPEX가 높은 수익률을 만들면 반드시 나쁜 것은 아니다.

---

# 34. Owner Earnings

개념적으로:

\[
OwnerEarnings
\approx
OCF - MaintenanceCAPEX
\]

보다 정밀하게는 운전자본과 비정상 현금흐름을 조정한다.

목적:

- 회계상 이익이 아니라 실제 주주에게 귀속 가능한 경제적 현금창출력을 본다.

# 35. CCC

일반 제조업:

\[
CCC = DIO + DSO - DPO
\]

- DIO: 재고 회전일수
- DSO: 매출채권 회수일수
- DPO: 매입채무 지급일수

해석:

- CCC 증가 → 운전자본 부담 가능성
- CCC 감소 → 현금전환 개선 가능성

업종별 대체 지표를 사용한다.

예:

- 금융: CET1, NIM, credit cost
- 장비: 수주잔고의 매출/현금 전환
- 반도체: 재고, OCF-CAPEX
- 보험: CSM, K-ICS, 손해율

# 38. 기업가치에서 적정매수가로 변환

## 38.1 1단계: BPS 계산

\[
BPS = Equity / SharesOutstanding
\]

## 38.2 2단계: fair PBR 계산

\[
fair\_pbr =
\left(
\frac{1+ROE}{1.11}
\right)^3
\]

## 38.3 3단계: 기업가치 기준 적정가격

\[
FairPrice = BPS \times fair\_pbr
\]

## 38.4 4단계: sector 기준과 비교

보다 보수적인 방법의 예:

\[
ReferencePBR = \min(company\ fair\ PBR,\ sector\ fair\ PBR)
\]

단, 업종 특성상 company fair PBR을 sector보다 높게 인정할 명확한 근거가 있다면 기계적으로 min을 쓰지 않는다.

## 38.5 5단계: 안전마진 시나리오 [권장 구현]

단일 적정가 대신 할인 시나리오를 만든다.

\[
BuyPrice(d) = FairPrice \times (1-d)
\]

예:

- d=0%: fair value
- d=10%: 보수적 1차 기준
- d=20%: 높은 안전마진
- d=30%: 큰 악재/사이클 저점 가정

## 38.6 6단계: 차트와 합친다

기업가치 적정가격이 80,000원이라고 해도 실제 차트가:

- 76,000-78,000원 강한 지지
- 71,000-73,000원 2차 지지

라면 실전 매수구간은 이 zone과 결합한다.

즉:

**기업가치가 가격의 상한을 만들고, 차트가 실제 진입 가격을 정교화한다.**

# PART IV. 실제 기업 예시 — 삼성전자 2025년 연결재무

## 39. 예시 목적

이 예시는 **산식 시연용**이다.

특정 시점의 매수 추천이 아니다.

특히 삼성전자는 반도체 사이클, AI/HBM 기대, 파운드리 개선 기대 등으로 시장이 미래 ROE를 크게 선반영할 수 있으므로, **2025년 trailing ROE만 3년 고정한다는 가정은 매우 보수적**이다.

---

# 40. 삼성전자 5년 실적

공식 삼성전자 자료의 연결 기준 핵심 실적을 단순화하면 다음과 같다.

단위: 조 원

| 연도 | 매출 | 영업이익 | 영업이익률 | 당기순이익 | 해석 |
|---|---:|---:|---:|---:|---|
| 2021 | 279.6 | 51.6 | 18.5% | 39.9 | 메모리 호황과 높은 수익성 |
| 2022 | 302.2 | 43.4 | 14.4% | 55.7 | 매출 증가, 영업마진 둔화 |
| 2023 | 258.9 | 6.6 | 2.5% | 15.5 | 반도체 다운사이클 영향 |
| 2024 | 300.9 | 32.7 | 10.9% | 34.5 | 이익 회복 |
| 2025 | 333.6 | 43.6 | 13.1% | 45.2 | 매출 최고치, 이익 개선 |

이 표만 봐도 삼성전자는 2023년 급격한 이익 저점 후 2024-2025년에 회복했다.

따라서 2025년 한 해 ROE를 영구 정상 ROE로 보는 것은 위험하다. **mid-cycle ROE와 forward ROE를 따로 추정하는 것이 더 적절하다.**

---

# 41. 2025년 ROE 계산

공식 연결 공시 기준:

- 2025년 지배기업 소유주지분 순이익: 약 44.261조 원
- 2024년 비지배지분 제외 자본총계: 약 391.688조 원
- 2025년 비지배지분 제외 자본총계: 약 424.313조 원

평균 지배주주 자기자본:

\[
AverageEquity =
\frac{391.688+424.313}{2}
=408.0005조원
\]

ROE:

\[
ROE =
\frac{44.261}{408.0005}
=10.85\%
\]

따라서 이 예시의 trailing ROE는 약 **10.85%**로 둔다.

---

# 42. ROA 계산

공식 연결 공시 기준:

- 2024년 총자산: 약 514.532조 원
- 2025년 총자산: 약 566.942조 원
- 2025년 당기순이익: 약 45.207조 원

평균 총자산:

\[
AverageAssets =
\frac{514.532+566.942}{2}
=540.737조원
\]

ROA:

\[
ROA =
\frac{45.207}{540.737}
=8.36\%
\]

제조업 기준으로는 자산효율이 낮은 수준은 아니지만, 삼성전자는 대규모 설비투자 산업이므로 CAPEX와 반도체 cycle을 함께 봐야 한다.

---

# 43. fair PBR 계산

가정:

- ROE = 10.85%
- discount rate = 11%
- N = 3년

\[
fair\_pbr =
\left(
\frac{1+0.1085}{1+0.11}
\right)^3
\]

\[
=
(0.9986)^3
\approx0.996
\]

즉 이 단순 모델에서 2025 trailing ROE만 3년 지속된다고 가정하면 fair PBR은 약 **1.00배**다.

### 해석

ROE 10.85%가 요구수익률 11%와 거의 같기 때문이다.

이 모델은 다음을 말한다.

> 2025년 수준의 자본수익률이 향후 3년 유지된다는 가정만 놓고 보면 장부가치보다 높은 프리미엄을 크게 정당화하기 어렵다.

하지만 시장이 향후 ROE 15%-20% 회복을 기대한다면 fair PBR은 크게 달라진다.

---

# 44. BPS 계산

2025년 말 공식 주식 정보 단순화:

- 보통주 발행: 5,919,637,922주
- 우선주 발행: 815,974,664주
- 총 발행주식: 6,735,612,586주
- 보유 자기주식: 105,432,448주
- 단순 유통주식수: 6,630,180,138주

지배기업 소유주지분:

\[
Equity = 424.313조원
\]

단순화 BPS:

\[
BPS =
\frac{424.313조원}{6,630,180,138주}
\approx63,997원
\]

즉 통합 주식수 기준 단순화 BPS는 약 **64,000원**이다.

### 중요 한계

삼성전자는 보통주와 우선주가 동시에 존재한다.

따라서 이 BPS는 **산식 교육용 통합 BPS**다. 실제 보통주 PBR과 정확히 맞추려면 보통주/우선주의 권리와 데이터 공급자의 BPS 산식에 맞춰야 한다.

# 45. fair price 계산

\[
FairPrice = BPS \times fair\_pbr
\]

\[
=63,997원\times0.996
\approx63,735원
\]

따라서 2025 trailing ROE만 3년 지속된다는 매우 단순하고 보수적인 가정의 fair price는 약 **63,700원**이다.

이 값은 삼성전자의 진짜 목표주가라는 뜻이 아니다.

오히려 이 결과는 다음 교훈을 보여준다.

> 시장가격이 이 가격보다 훨씬 높다면 시장은 2025년 ROE가 아니라 향후 더 높은 ROE, 이익성장, AI/HBM 성장, 파운드리 개선 등을 선반영하고 있다는 뜻일 수 있다.

# 46. 실제 시장가격 스냅샷을 넣은 expected return 예시

삼성전자 공식 공시에 따르면 2026년 3월 30일 보통주 종가는 **176,300원**이었다.

교육용으로 위에서 구한 단순 BPS 63,997원을 사용하면:

\[
PBR =
\frac{176,300}{63,997}
\approx2.75배
\]

이 PBR과 trailing ROE 10.85%를 그대로 넣으면:

\[
ExpectedReturn =
\frac{1.1085}{2.75^{1/3}}-1
\]

결과는 약 **-20.9%**다.

### 반드시 주의

이 -20.9%를 실제 3년 수익률 예측으로 해석하면 안 된다.

이 값은 다음 가정에서만 성립하는 **모델 내부 신호**다.

- ROE가 10.85%에 머문다.
- PBR 정상화가 발생한다.
- 성장 기대를 별도로 반영하지 않는다.
- 반도체 cycle과 미래 이익 급증을 반영하지 않는다.

즉 시장이 훨씬 높은 가격을 주고 있다면, 모델이 틀렸다기보다 **시장과 모델의 미래 ROE 가정이 크게 다르다**는 뜻일 수 있다.

# 47. PBR별 expected return 민감도

ROE 10.85%, N=3 기준:

| 시장 PBR | 계산 expected return |
|---:|---:|
| 0.8배 | 약 +19.4% |
| 1.0배 | 약 +10.8% |
| 1.2배 | 약 +4.3% |
| 1.5배 | 약 -3.2% |
| 1.8배 | 약 -8.9% |
| 2.0배 | 약 -12.0% |
| 2.75배 | 약 -20.9% |

핵심:

**같은 기업이라도 어떤 PBR에 사느냐에 따라 기대수익률은 크게 달라진다.**

# 48. ROE별 fair PBR 민감도 [권장 활용]

할인율 11%, N=3일 때:

\[
fair\_pbr =
\left(
\frac{1+ROE}{1.11}
\right)^3
\]

예시:

| 정상화 ROE | fair PBR 해석 |
|---:|---|
| 8% | 1배 미만이 자연스러움 |
| 11% | 약 1배 |
| 15% | 1배 이상 프리미엄 가능 |
| 20% | 더 높은 프리미엄 정당화 가능 |

따라서 삼성전자처럼 사이클이 큰 기업은 trailing ROE 하나보다:

- bear ROE
- base ROE
- bull ROE

세 가지 시나리오를 만들어야 한다.

# 52. 최종 실전 의사결정 알고리즘

```python
def final_stock_decision(chart, value, supply, industry):
    # 1. 현재 위치
    if chart.current_price_near_major_resistance and chart.rr <= 1:
        new_entry = "추격 금지"
    else:
        new_entry = "조건 확인"

    # 2. 가치
    if value.roe_quality_low or value.cashflow_deteriorating:
        value_gate = False
    else:
        value_gate = True

    # 3. 수급
    if supply.type == "distribution":
        supply_gate = False
    else:
        supply_gate = True

    # 4. 1차 지지 접근
    support_entry = (
        chart.in_first_support
        and chart.pullback_volume_is_quiet
        and supply_gate
        and value_gate
    )

    # 5. 확인 매수
    confirm_entry = (
        chart.close_above_resistance
        and chart.hold_above_resistance
        and chart.volume_ratio >= 1.2
        and supply.foreign_institution_confirm
    )

    # 6. 무효화
    invalid = (
        chart.close_below_invalidation
        and (
            chart.volume_expands_on_drop
            or supply.type == "distribution"
        )
    )

    # 7. 보유자
    if invalid:
        holder = "방어/비중 축소 검토"
    elif chart.near_long_term_extreme_upper and chart.distribution_candle:
        holder = "일부 비중 관리"
    else:
        holder = "핵심 지지 유지 시 보유"

    return {
        "new_entry": new_entry,
        "support_entry": support_entry,
        "confirm_entry": confirm_entry,
        "holder": holder,
        "invalid": invalid,
    }
```

# 57. 핵심 요약

## 차트분석

차트분석의 핵심은:

> 어디서 사고, 어디서 틀렸다고 인정할 것인가.

판단 순서:

**현재가 → 지지/저항/박스 → Bollinger → OHLC → 거래량 → RSI/MACD → 수급 → Elliott/Fibonacci → 손익비 → 무효화**

## 기업가치 분석

기업가치의 핵심은:

> 이 가격을 지불할 만큼 기업의 자본효율과 현금창출력이 좋은가.

판단 순서:

**5년 실적 → 정상화 이익 → ROE/ROA → PER/PBR → fair PBR → expected return → OCF/CAPEX/FCF → 주주환원 → sector valuation → 가치가격**

## 최종 결론

최종적으로 세 가지를 별도로 판단한다.

1. **좋은 회사인가?**
2. **좋은 차트인가?**
3. **지금 가격이 좋은가?**

세 조건이 모두 맞을 때 신규매수 신뢰도가 가장 높다.
