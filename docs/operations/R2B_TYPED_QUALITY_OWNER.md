# R2B-R3 Typed Business Quality

Archive-only entry point: `scripts.r2b_r3_preflight`. No runtime registration,
acquisition, model dispatcher, persistence or delivery is added.

The preimplementation matrix is a separate immutable local artifact. Its 22
rows classify seven existing canonical records, fourteen reconstructible source
owners and one UNKNOWN_LIMIT non-applicability case. This is not a ticker rule.

## Source Owner

`canonical_business_quality_owner` replays `versioned_business_stock_owner`,
which verifies exact source versions, subject identity, issuer bridge, original
quality receipts and comparative facts. It uses the existing source-family
validators and `financial-quality-taint-v2`, with unchanged thresholds. Metadata
projection follows `unified_stock_owner._financial`. Canonical aggregate state
has the same precedence as `ai_review_service`.

Selected reported inputs are the scope, not all corporate financial information.
Absent revenue/operating-income values are not made usable. Field-local SEC
denials survive as owned reasons; an independent usable field does not erase
the omitted field's conflict. No per-share, valuation or directional-disclosure
quality is transferred. Foreign issuer split-field sources retain separate
replay receipts. A legal-issuer bridge keeps its original OpenDART source.

The detached supplement contains the real canonical quality fact, input fact
hashes, original quality/input hashes, subject/security/issuer ownership, source
period/provider, owner version and reproducible receipt. Existing records are
never replaced. Registration allows only CONTEXT and CONFIDENCE; existing source
permissions remain unchanged. The raw sealed ZIP/packet hashes remain exact.
Detached packet/evidence self-hashes are recomputed after annotation and final
time/visibility projection, with the sealed parent packet identity preserved.
The historical R2 default path is unchanged; only R3 opts into this view owner.

## Consumption Gate

Missing expected owner output fails upstream with
`EXPECTED_BUSINESS_QUALITY_OWNER_OUTPUT_MISSING`; it produces no model-visible
effect. Present clean records yield NONE, owned limitations CONFIDENCE_ONLY with
the exact ref. UNKNOWN_LIMIT produces no financial-quality claim or fake ref.
Legacy ref/reason validation remains unchanged. The historical R2B-R2 projector
is not globally changed: R3 enforces completeness before entering that adapter.

All 22 actual A normalization/legacy-validation probes complete before any B
transformation. These are mechanical probes, never AI investment conclusions.
Input readiness and blind-comparison permission are separate gates.

## Blind Boundary

Source-only blind records may be inspected; independent judgments may not.
All input comparative fact hashes must match the blind source. Concrete new
anomaly/conflict reasons are conservatively material unless already recorded in
the source-only review. A generic hard-error category is not a substitute for
the specific diagnosis. Exact code presence is a conservative disclosure gate,
not a claim that every wording difference necessarily changes a human verdict.
