# R2B Whole-Decision Limitation

Archive-only contract: `r2b-whole-decision-limitation-v1`.
No production registration, delivery, persistence or model-dispatch entry point.

## Decision Ownership

`EVIDENCE_BASED` delegates the unchanged R4-R4 -> R3 -> R2 schema and validator.
`UNKNOWN_LIMIT` requires a complete source assembly, mandatory price/technical
components, valid source authority, zero Overall/Holder directional entitlement,
zero observed directional capabilities and explicit source-use denials.
Missing source assembly is an error, not a limitation decision.

The strict limitation schema fixes Overall, New Buyer and Holder to `OBSERVE`.
Both directional scores and directional confidence are null. Nonempty unknowns
and next-evidence arrays contain only bound source-recovery IDs. No free-form
directional prose, HOLD, ratio, price-triggered upgrade or inferred action is
accepted. The deterministic renderer distinguishes no evidence from balanced
evidence. Context and technical evidence cannot create business direction.

## Stored Rules

`versioned-strategy-metadata-v1` binds the canonical rule to the exact sealed
Class-C local document, thesis record/version/hash, security identity, currency,
basis and original values. `InvestmentThesis.created_at` uses the existing UTC
storage contract; it is version creation time, not an invented market timestamp.
The original undated canonical fact is not rewritten. The derivative view is
hash-linked to the unchanged source authority and cannot widen allowed uses.

If binding fails, the rule and potentially copied thesis/expectations prose are
excluded. Independently sourced technical values remain independent, including
coincident prices. Exclusion never silently becomes current-date metadata.

## Preflight

`scripts/r2b_r2_preflight.py` has a network-denial guard and an exact source read
allowlist. It verifies source ZIP entries, all five source identities, the blind
ZIP and the neutral freeze receipt. External assessment content is forbidden.

Offline probes are not candidates or AI decisions. They exercise Core, current
source-use projection, provider schema, actual A materialization and downstream
B input transformation. A schema-only pass is insufficient. A failed A
materialization blocks the dependent B/New Buyer/Holder path, while every other
subject is still audited. No eligible-subset execution is allowed.

Canonical source-time checks and versioned strategy checks are explicit.
Noncanonical metadata retains its frozen source metadata timestamp; this audit
does not promote a context construction timestamp to a filing/publication time.
No prompt/model-input seal may be issued while whole-cohort readiness is blocked.
