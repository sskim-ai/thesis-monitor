# Consumption-Driven Source Closure

R2A-R4 consumes the graph frozen in `UNIFIED_CONSUMED_SOURCE_GRAPH.md`.
The graph is a reachability map, not a grant of source authority.
The A5/B4/C12/D3 role inventory, provider exclusions and activation OFF remain.

## Implemented Boundaries

- Optional Class C can retain its acquisition class with a bound artifact,
  record/version and independently replayed owner denial. It carries no value.
  Mandatory C cannot use this path. No missing-to-zero conversion exists.
- `unified_persisted_owner_bridge` reconstructs only declared selected records
  in ephemeral SQLite and reruns the existing read-only R3 projection owner.
  It checks role/provider family, record inventory, owner fingerprints and
  normalized output. It never opens operating storage or refreshes a provider.
- Macro/Fed projections retain original observation/publication time. Stored
  Fed AI implications are excluded. No new temporal threshold is introduced.
- Canonical CF/WC projection invokes the existing consumption verdict and
  preserves input fact versions, source dates and the selected relation. It
  rejects taint, future inputs, identity conflicts and cyclic derivation.
  This is not an installed canonical OwnerAdapter: the independent formal
  selection source has not been bound to the full packet. Both
  `formal_source_binding_verified` and `complete_source_adapter_qualified`
  remain false, even when the local supplied-input verdict is eligible.
- US market callback rebuilds all configured symbol observations from verified
  child bytes using the same normalizer as `OhlcvMarketProvider.collect`.
- Kiwoom callback invokes the real market-context service against exact saved
  accepted pages and verifies its requests and cursor order. It supports the
  complete successful-page plan; failed/retry child graphs remain fail-closed.
  Replay uses opaque cursor-hash handles, not reconstructed secret cursors.
- Composition compares a child-derived aggregate with the bound candidate hash.
  A callback cannot qualify a pre-normalized aggregate by returning it unchanged.

## Limits and Required Next Closure

1. The stock source materializer is not assembled. It must connect the accepted
   chart/price and local/financial owners to exact typed evidence, observed
   business propositions, current formal selection and valuation dependencies
   for US14/KR8. The legacy `_stock_packet` is not a safe substitute: it also
   reaches prior assessments, implicit cache/report paths and rendering.
   Optional CF/WC or estimates may be unavailable; an empty observed-business
   union is still forbidden. Finnhub provider-defined forwardPE does not qualify
   as the exact EPS/period/security denominator required by Pass B. The existing
   estimate inventory denial is connected, but an eligible-estimate selection
   path and its required positive/negative proofs remain unimplemented.
2. The mandatory US KRX night owner has no concrete full acquisition/history
   aggregate replay callback. Existing raw parsing alone does not reproduce the
   two-product plus same-contract D/W/M path or bind all history dependencies.
   This is an offline ownership gap, not a request to fetch newer values.

These are actual consumed paths. Optional event/Nasdaq absence and unconsumed
financial domains are not additional whole-packet blockers. Optional values
must not be supplied through an unimplemented replay path.

`unified_consumption_audit` inventories declared historical source-only packets
through existing Market/decision/ownership builders, without model output or
rendering. It identifies owner families, not fully verified source lineage.
Historical packet hashes must never be reused as newly assembled packet hashes.
