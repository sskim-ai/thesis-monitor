# Message Quality v2 Root Cause

The instruction-commit baseline was safe but selected generic Free Analyst synthesis whenever the
current sparse message did not itself expose a strong business relation. The deterministic fallback
already held entity-specific thesis evidence, but the analysis catalog did not use it as supporting
evidence. That produced 26 generic lines in 13 US messages and 10 lines in five KR messages.

A second KR defect appended the canonical supply section after a shorter renderer positioning
section, allowing the same interpretation to appear twice. A third defect let Inventory lead even
when a current entity thesis existed, most visibly in Hanwha Aerospace.

Repair:

1. Add deterministic reference evidence under the same owner with separate refs.
2. Fail closed on entity/ticker/market/packet owner mismatch.
3. Lead with the stored entity thesis before auxiliary Inventory evidence.
4. Preserve the canonical supply tuple in one section owner.
5. Reject generic synthesis when a specific thesis link is available.
6. Reject duplicate substantive claims across rendered sections.

No quality threshold or runtime validator was relaxed.
