# 003690 Holder Variable Control

The rejected holder sentence separated chart-boundary failure from combined-ratio deterioration
or catastrophe-loss-driven fundamental damage. Those are valid reinsurance holder variables, but
the generic holder vocabulary did not recognize them.

The contract now recognizes combined ratio, loss ratio, catastrophe loss, underwriting, and
fundamental damage for any routed insurance/reinsurance subject. No `003690` condition or sentence
is hardcoded.

`003690_HOLDER_VARIABLE_BINDING = PASS`
