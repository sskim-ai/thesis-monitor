# Repetition Taxonomy

Date: 2026-09-04 KST

Status: shadow-only; no production mutation.

The five classes are `RENDERER_OWNED_REPEAT`, `MODEL_OWNED_SUBSTANTIVE_REPEAT`, `REQUIRED_SAFETY_REPEAT`, `BENIGN_TEMPLATE_REPEAT`, and `MATERIAL_SPAM_REPEAT`. Only material spam is a candidate for escalation, and the current shadow policy still records it as advisory Class C unless a separate factual/semantic contradiction exists.
