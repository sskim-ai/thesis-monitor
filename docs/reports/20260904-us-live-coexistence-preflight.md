# US Live Coexistence Preflight

The protected US natural window was given priority. Shadow execution was paused before the window and resumed only after the authoritative run reached terminal delivery and the shared runtime was released.

| Gate | Value |
| --- | --- |
| Resource interference | `POSSIBLE` |
| Pause required | `YES` |
| Shadow calls during protected window | `0` |
| Production scheduler mutation | `0` |
| Production send from shadow | `0` |

The later forensic review is intentionally not an input to the fresh-first experiment.
