# Bounded Validation Production Change Set

Only the proven bounded pieces were promoted:

- `source-owned-logical-condition-v1` for condition identity, severity, operator, and coverage.
- `bounded-production-validation-policy-v1` separating deterministic hard safety, semantic hard safety, and soft quality.
- `numeric-reference-language-normalizer-v1`, a single pre-bind pass that removes redundant authored labels and moves ordinary Korean particles into structured numeric-reference metadata.
- A structured exact-span bridge restores the one proven legacy valuation grammar corruption only when the canonical typed span identifies one unique match; ambiguous prose remains untouched and fails closed.
- KR/US real E2E scripts now require both `DATA_DIR` and the active SQLite engine URL to resolve to the isolated output directory. US can continue the same accepted claim after a pre-send validator repair without rerunning the model.
- Material repetition remains blocked; benign typed and renderer-owned repetition becomes a soft warning.
- The already-proven child-wait, command-timeout, terminal-receipt, lease, and fencing commits were ported without modification.

No ticker/value/sentence allowlist, validator threshold relaxation, AI-reviewer universal veto, decision-weight change, schema migration, scheduler change, or recipient change was introduced.
