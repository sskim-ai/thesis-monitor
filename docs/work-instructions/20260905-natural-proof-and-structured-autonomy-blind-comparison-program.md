# 25. Agreement levels

Per ticker classify:

```text
FULL_AGREEMENT
BOUNDARY_DIFFERENCE
MEANINGFUL_DIFFERENCE
MAJOR_DIFFERENCE
```

Suggested interpretation:

FULL_AGREEMENT:
- same direction
- balance within 0.5
- same new-buyer and holder stance

BOUNDARY_DIFFERENCE:
- same general direction
- <= 1.0 balance difference
- action context differs near threshold

MEANINGFUL_DIFFERENCE:
- label or new-buyer/holder stance differs materially

MAJOR_DIFFERENCE:
- BUY vs SELL
- ATTRACTIVE vs AVOID
- HOLDABLE vs REDUCE
without clear evidence-basis explanation

# 43. Final principle

The next question is no longer only:

```text
"Can the system produce V2?"
```

It is also:

```text
"Given the same facts,
does the autonomous investment judgment make sense,
remain stable,
and behave similarly to an independent reasoned reviewer?"
```

It is a second decision lens.

Use disagreement to discover:
- weighting problems
- expectation problems
- valuation problems
- timing problems
- Unknown handling problems
- action-context problems

not to force the AI toward a predetermined label distribution.
