# 12. Full condition vs non-exhaustive example

Avoid a new over-strict failure.

A writer may legitimately mention one branch of an OR condition as an example.

Distinguish:

```text
FULL
NON_EXHAUSTIVE_EXAMPLE

```

Example:

Source:

```text
A OR B
```

Allowed:

```text
"예를 들어 A가 발생하면 논리를 재검토해야 합니다."
```

if metadata says:

```text
coverage_mode = NON_EXHAUSTIVE_EXAMPLE
source branch = A
```

Not allowed:

```text
"A와 B가 함께 발생해야 무효화됩니다."
```

when metadata claims to represent the full source condition.

This distinction prevents operator validation from becoming another language-overfitting layer.
