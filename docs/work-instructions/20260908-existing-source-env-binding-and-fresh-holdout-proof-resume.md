# 34. Failure decision matrix

## A. Existing protected config not found

```text
STOP before candidate loop
real model calls = 0
next_scope = EXISTING_SOURCE_CONFIGURATION_BINDING_OPERATOR_REPAIR
```

## B. Config found but US/KR smoke fails

```text
STOP before candidate loop
report exact source-client failure
real model calls = 0
```

Do not scan 65 candidates.

## C. Config smoke passes but one market cannot fill source target

Complete the other market's bounded diagnosis.

Then:

```text
STOP pre-model
```

Do not lower evidence requirements.

## D. Fresh source lock succeeds, runtime later fails

Preserve all successful context evidence.

Stop at first failed context.

Do not retry automatically.

Do not auto-select another holdout.

## E. All FIRST/A/B/C hard gates and formal stability/generalization pass

Then:

```text
readiness =
READY_FOR_MONITORING_BOOTSTRAP_INTEGRATION_REVIEW

next_scope =
Monitoring Bootstrap Integration Review
```

Monitoring remains paused until separately authorized.

```text
bind existing protected config

```

Not:

