# 4. Root cause

Current non-financial routing behavior effectively assumes:

> one document/reference must have one already-normalized distinct nonempty label.

When the exact SEC filing/index parser emits multiple text fragments for one logical link
description, the router sees multiple distinct labels and refuses category matching.

This is too early a fail-closed point.

The correct ownership chain is:

`exact SEC link/reference`
→ `ordered text fragments belonging to that one logical reference`
→ `LogicalExhibitDescription`
→ `purpose-routing classifier`

Do not classify individual fragments independently.
Do not merge unrelated anchors/references merely because they point to the same URL.
