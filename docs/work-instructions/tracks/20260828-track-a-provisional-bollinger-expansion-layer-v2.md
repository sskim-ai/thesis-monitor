# Track A — Provisional Bollinger Expansion Layer

Enable one optional user-facing provisional Bollinger line per stock.

Use valid in-progress D/W/M bars only.

Required label:
`잠정 볼린저 지지/저항(<timeframe>·진행중)`

Never feed provisional values into near S/R, major S/R, stored price rules, Fib, or wave anchors.

MU is the primary positive control.
SNDK/WULF are no-bypass negative controls.
