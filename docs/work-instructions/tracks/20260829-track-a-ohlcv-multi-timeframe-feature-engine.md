# Track A — OHLCV Multi-Timeframe Feature Engine

Build/reuse a documented backend-owned feature catalog from safe OHLCV.

Required D/W/M families:
- returns / drawdown / rolling highs-lows
- SMA / EMA
- MACD / signal / histogram
- RSI
- ATR / realized volatility
- Bollinger
- ADX / DMI
- ROC / momentum
- Stochastic
- valid volume-derived signals
- breakout/channel states
- validated divergence only

Completed bars authoritative.
Partial-bar features explicitly provisional.
No AI-calculated features.
No arbitrary third-party TA dump.
