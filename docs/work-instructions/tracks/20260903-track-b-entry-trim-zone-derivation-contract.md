# Track B — Entry / Trim Zone Derivation Contract

Before Codex judgment, build a verified price map:
current / support / resistance / major levels / confirmation / warning / invalidation.

New-buyer:
entry zone only from verified support or confirmation structure.
If no safe zone, return none or a recovery condition.

Holder:
trim/sell-review zone only from verified resistance/valuation context.
It is a reassessment zone, NOT an automatic sell target.

Keep downside warning/invalidation separate.
No invented stop-loss or target.
Validate every rendered price-zone number.
