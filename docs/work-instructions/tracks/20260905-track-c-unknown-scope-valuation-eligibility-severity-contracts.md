# Track C — Unknown Scope / Valuation Eligibility / Severity Contracts

Machine-readable contracts:

1. Evidence eligibility:
   prose / valuation / numeric / semantic eligibility.

2. Severity:
   weakening cannot become invalidation without invalidation-owned evidence.

3. Unknown scope:
   natural paraphrase allowed;
   new causal driver requires its own evidence ref.

Primary owner must be structured metadata, not free-prose keyword parsing.
