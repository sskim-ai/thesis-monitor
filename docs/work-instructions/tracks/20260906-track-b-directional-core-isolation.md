# Track B — Directional Core Isolation

Build a fenced Directional Core that does not receive technical or supply evidence.

It owns:
overall direction
BUY:SELL balance
HOLD lean
fundamental new-buyer stance
fundamental holder stance
business invalidation
business reevaluation.

Thresholds stay unchanged.

Prefer a separate model invocation whose input contains only directional evidence.

Price timing must be unable to mutate the core result.
