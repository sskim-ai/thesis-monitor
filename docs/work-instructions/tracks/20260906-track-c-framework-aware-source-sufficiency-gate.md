# Track C — Framework-Aware Pre-Model Source Sufficiency Gate

Create an explainable deterministic source-sufficiency contract.

Directional judgment requires:
- hard-valid identity/security basis
- issuer-specific fundamental/business anchor
- framework-appropriate financial/operating/liquidity/regulatory anchor
- acceptable freshness

Do not require the same metric for every industry.

Price context alone is never sufficient.
Valuation may remain Unknown without automatically blocking business-direction judgment.

If insufficient:
do not call BUY/HOLD/SELL model.
Return source insufficiency only.
